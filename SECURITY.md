# Security reporting

ScoreBrush handles local files and untrusted PDF, ZIP, notation and AI-response
content. Do not put private scores, profiles, personal paths or an unredacted
exploit report in a public issue.

Report vulnerabilities privately with **Report a vulnerability** in the
repository's **Security → Advisories** interface:
https://github.com/aug5thmusic/scorebrush/security/advisories

Provide the affected version, a minimal synthetic reproduction, expected impact
and redacted diagnostics. Do not access other people's data or test against
production transcription folders. No response-time commitment is provided.
